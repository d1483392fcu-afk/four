# 流程圖：數位足跡-碳排放行為帳本

本文件根據專案需求與架構設計，呈現「使用者操作流程」與「系統資料互動序列」，幫助開發團隊清楚理解功能串接邏輯。

## 1. 使用者流程圖（User Flow）

此圖表展示使用者從開啟網頁到進行各項操作（如登錄行為、查看報表、設定目標）的完整路徑。

```mermaid
flowchart LR
    A([使用者開啟網頁]) --> B{是否已登入？}
    B -->|否| C[登入/註冊頁面]
    C -->|登入成功| D[首頁 / 數據總覽儀表板]
    B -->|是| D
    
    D --> E{選擇操作功能}
    
    E -->|1. 新增行為| F[進入行為登錄頁面]
    F --> F1[選擇行為分類：食衣住行]
    F1 --> F2[填寫行為細節參數]
    F2 --> F3[送出紀錄]
    F3 --> F4[系統顯示：碳排計算結果與低碳替代建議]
    F4 -->|確認後返回| D
    
    E -->|2. 查看報表| G[進入數據視覺化報表頁面]
    G --> G1[檢視圓餅圖與折線圖]
    G1 -->|返回| D
    
    E -->|3. 設定目標| H[進入目標設定頁面]
    H --> H1[設定本月減碳目標值]
    H1 -->|儲存| D
    
    E -->|4. 登出| I([登出系統])
    I --> C
```

## 2. 系統序列圖（Sequence Diagram）

以下針對核心功能**「新增行為紀錄、計算碳排並獲得建議」**，描述前端瀏覽器、後端控制器與資料庫之間的資料流動。

```mermaid
sequenceDiagram
    actor User as 使用者
    participant Browser as 瀏覽器
    participant Flask as Flask (ledger.py)
    participant Model as 業務邏輯與模型
    participant DB as SQLite 資料庫

    User->>Browser: 填寫行為表單並點擊「送出」<br>(例：獨自開車 10 公里)
    Browser->>Flask: POST /record (攜帶表單資料)
    
    Flask->>Model: 解析資料並呼叫碳排計算引擎
    Model-->>Flask: 回傳計算結果 (例：產生 2.5kg 碳排)
    
    Flask->>Model: 根據行為類型，呼叫低碳建議引擎
    Model-->>Flask: 回傳替代建議 (例：改搭大眾運輸可減少 80% 碳排)
    
    Flask->>DB: INSERT INTO records<br>(寫入行為、碳排量、時間戳記)
    DB-->>Flask: 資料庫寫入成功
    
    Flask->>Browser: 渲染結果提示畫面<br>(或將計算結果與建議 Flash 到前端)
    Browser-->>User: 顯示成功訊息、新增的碳排數據及智慧建議
```

## 3. 功能清單與路由對照表

本表列出系統主要功能對應的 URL 路徑與 HTTP 請求方法，作為後續 API 設計與前後端串接的參考依據。

| 功能模組 | 功能名稱 | URL 路徑 | HTTP 方法 | 說明 |
| :--- | :--- | :--- | :--- | :--- |
| **會員驗證** | 使用者註冊 | `/register` | `GET`, `POST` | `GET`: 顯示註冊表單<br>`POST`: 處理註冊邏輯 |
| | 使用者登入 | `/login` | `GET`, `POST` | `GET`: 顯示登入表單<br>`POST`: 處理登入邏輯 |
| | 使用者登出 | `/logout` | `GET` | 清除 Session 並導回登入頁 |
| **數據總覽** | 首頁 / 儀表板 | `/` | `GET` | 顯示個人累積碳足跡、目標達成進度 |
| **行為帳本** | 登錄行為 | `/record` | `GET`, `POST` | `GET`: 顯示行為登錄介面<br>`POST`: 接收資料，計算碳排並儲存 |
| | 刪除行為紀錄 | `/record/<id>/delete` | `POST` | 刪除錯誤輸入的歷史紀錄 |
| **統計報表** | 數據視覺化 | `/report` | `GET` | 顯示以週或月為單位的圖表數據 (折線圖/圓餅圖) |
| **目標管理** | 設定減碳目標 | `/target` | `GET`, `POST` | 設定或修改個人每月的減碳目標基準 |

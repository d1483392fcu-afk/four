# PRD：數位足跡-碳排放行為帳本

## 1. 專案概述
- **背景與動機**：面對氣候變遷，個人減碳行動至關重要，但由於日常行為帶來的環境影響難數量化，多數人難以持續保持動力。本系統期望將「記帳」的邏輯應用於環境數據，將抽象的環保行為具體數據化。
- **目標用戶**：大學生、教職員、環保實踐者。
- **核心價值主張**：透過簡單的行為登入與自動化的碳排放計算，提供視覺化的成就感，並給予低碳替代建議，協助使用者有意識地達成減碳目標。

## 2. 功能需求

### 2.1 行為分類登入
- **使用者故事**：作為一名**環保實踐者**，我希望**能分類紀錄食衣住行等日常行為（如搭乘捷運、吃素食等）**，以便**有系統地留下我的數位碳足跡**。

### 2.2 碳排放自動計算
- **使用者故事**：作為一名**大學生**，我希望**系統能根據我登入的行為自動計算增減的碳排放量**，以便**快速了解我的日常行為對環境造成的具體影響**。

### 2.3 數據視覺化報表
- **使用者故事**：作為一名**教職員**，我希望**能看到每週或每月的碳足跡折線圖與圓餅圖**，以便**清楚掌握我的減碳進度與主要碳排來源**。

### 2.4 減碳目標設定與追蹤
- **使用者故事**：作為一名**環保實踐者**，我希望**能設定每月的減碳目標並隨時追蹤達成率**，以便**督促自己持續改善生活習慣**。

### 2.5 智慧低碳替代建議
- **使用者故事**：作為一名**大學生**，我希望**系統能針對高碳排行為提供具體的低碳替代方案（例如：將獨自開車改為搭乘大眾運輸）**，以便**在下次行動時能做出更環保的選擇**。

## 3. 非功能需求
- **技術限制**：預計採用 Flask + Jinja2 作為後端與頁面渲染框架，並使用 SQLite 進行輕量級關聯式資料庫管理。
- **效能與安全考量**：
  - 系統需確保快速響應，頁面載入時間應小於 2 秒。
  - 使用者密碼需經過加密處理（如 bcrypt）儲存。
  - 保護使用者行為數據隱私，除公開分享外，不得任意暴露個人紀錄。

## 4. MVP 範圍

### Must Have (必須有)
- 使用者註冊與登入功能。
- 基礎四大類（食、衣、住、行）行為分類登入介面。
- 碳排放自動計算模組（後端需建立基礎碳排放係數表）。
- 個人歷史紀錄列表與簡單的數據視覺化（本月累積碳排）。

### Should Have (應該有)
- 減碳目標設定與進度條追蹤。
- 詳細的每週/每月圓餅圖與折線圖報表。

### Nice to Have (可以有)
- 智慧低碳替代建議（針對使用者常發生的行為進行推播）。
- 社交分享功能（一鍵生成成就卡片分享至社群平台）。
- 碳點數排行榜與實體獎勵兌換機制。
